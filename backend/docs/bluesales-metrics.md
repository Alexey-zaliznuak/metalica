# Время запросов BlueSales

`GET /api/dev-metrics?date=2026-09-15` и страница `/dev-metrics` доступны только роли ADMIN.
Без `date` возвращаются текущие сутки: 01:00–01:00 Europe/Moscow.

Каждый успешный HTTP/API-ответ сохраняется в `BluesalesRequestMetric`: метка,
метод, начало, завершение, длительность и начало отчётных суток. Длительность
измеряется монотонными часами от отправки до получения тела ответа. Очередь,
паузы, ошибки и неудачные попытки не учитываются. Каждая успешная страница
постраничного запроса учитывается отдельно. Период определяется по началу запроса.
Старые запросы до установки обновления восстановить нельзя.

Метка одного запроса:

```ts
await api.send('orders.get', payload, {
  priority: 'background',
  label: 'order-background-sync',
});
```

Метка всей операции, включая страницы и повторы:

```ts
await api.withLabel('order-background-sync', () => api.getOrders(from, to));
```

Явная метка запроса имеет приоритет над меткой операции. Без метки используется
имя метода (`orders.get`, `orders.updateMany` и т. п.). Метки обрезаются до 120
символов; не включайте в них персональные данные или идентификаторы заказов.

Готовые метки синков: `order-background-sync`, `lead-background-sync`,
`fast-sync`, `recent-backfill`, `startup-sync`, `order-manual-refresh`.

Прогноз использует темп за последний час, нормализованный по расписанию синков:
01:00–06:00 — пауза, 06:00–09:00 и 00:00–01:00 — треть дневного темпа.
Нужно минимум 15 минут наблюдения вне паузы и 5 успешных запросов. Ручные
операции входят в расход, но модель не предсказывает их отдельный поток.
3 часа — ориентир дашборда, автоматического отключения запросов нет.

Схема добавлена отдельной миграцией. Существующий Docker entrypoint применяет
Prisma schema при запуске; для окружений с migration deploy используйте
`npm run prisma:migrate`. После изменения схемы: `npm run prisma:generate`.
При недоступности БД ошибка записи метрики логируется, но уже успешный запрос
к BlueSales не повторяется, чтобы не дублировать внешнюю операцию.

Проверки: `npm run build`, затем
`node --test test/bluesales-metrics.test.cjs test/bluesales-sync.test.cjs`.
